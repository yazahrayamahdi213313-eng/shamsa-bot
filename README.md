# ربات توزیع متن توییت

## قابلیت‌ها
- کاربران مجاز هر بار فقط یک متن active دارند.
- متن فعال با کلیک مجدد تکراری دریافت نمی‌شود؛ همان assignment قبلی برمی‌گردد.
- با «استفاده کردم» وضعیت assignment به used تغییر می‌کند و در درخواست بعدی متن بعدی دریافت می‌شود.
- هر tweet در دیتابیس وضعیت `available / assigned / used` دارد.
- تاریخچه assignment ها در جدول جداگانه نگهداری می‌شود.
- تخصیص با `BEGIN IMMEDIATE` در SQLite اتمیک شده است.
- ورود گروهی TXT و CSV.
- پنل مدیریت برای افزودن، ویرایش، حذف، آزادسازی، تخصیص دستی، مدیریت دسترسی، جست‌وجو و آمار.

## نصب
Python 3.11+ پیشنهاد می‌شود.

```bash
py -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
```

بعد `.env` را باز کنید و BOT_TOKEN و ADMIN_IDS را تنظیم کنید.

اجرای ربات:

```bash
python bot.py
```

## فرمت TXT
روش اول:

```text
## TEXT 1
متن اول...

## TEXT 2
متن دوم...
```

روش دوم: هر متن با یک خط خالی از متن بعدی جدا شود.

## فرمت CSV
یک ستون با نام `text` داشته باشید:

```csv
text
"متن اول"
"متن دوم"
```

## نکته درباره دکمه کپی
Telegram برای CopyTextButton حداکثر 256 کاراکتر برای متنی که کپی می‌شود تعیین کرده است. برای متن‌های طولانی‌تر، متن عادی ارسال می‌شود تا کاربر از قابلیت Copy خود تلگرام استفاده کند.

## ساختار دیتابیس
### users
اطلاعات کاربر تلگرام و وضعیت دسترسی.

### tweets
متن اصلی و وضعیت فعلی آن.

### assignments
تاریخچه اینکه هر متن چه زمانی به چه کاربری اختصاص داده، استفاده یا آزاد شده است.

## منطق همزمانی
در `assign_for_user()` عملیات با `BEGIN IMMEDIATE` شروع می‌شود. ابتدا assignment فعال کاربر بررسی می‌شود و اگر وجود نداشت، اولین متن `available` داخل همان تراکنش انتخاب و `assigned` می‌شود و رکورد assignment ثبت می‌شود. در نتیجه دو درخواست همزمان نمی‌توانند یک متن را رزرو کنند.
